مدیریت آرشیو PS4 / PS5

پوشه آرشیو را انتخاب کنید؛ فایل‌ها آپلود، کپی یا جابه‌جا نمی‌شوند. برنامه فقط اطلاعات فایل‌ها را می‌خواند و برای بازی‌های شناسایی‌شده شورتکات ویندوزی می‌سازد.

آماده
خروجی داخل پوشه «PS Archive Shortcuts» در آرشیو انتخاب‌شده ساخته می‌شود؛ فایل اصلی کپی یا جابه‌جا نمی‌شود.
گزارش عیب‌یابی بررسی آنلاین (برای ارسال به توسعه‌دهنده)

اسم بازی را یک بار برای هر Title ID وارد کنید؛ برای همه آیتم‌های همان بازی (Base، Update، DLC) اعمال می‌شود و ذخیره می‌ماند. برای دیدن نسخه‌ها و دانلود آپدیت، روی لینک منبع کلیک کنید.

تنظیمات جست‌وجو

کلیدها فقط روی همین دستگاه ذخیره می‌شوند. روش پیشنهادی «فقط خود سایت‌ها» است و کلید نمی‌خواهد؛ Serper فقط پشتیبان است. (Google Custom Search برای حساب‌های جدید بسته شده و کنار گذاشته شد.)
